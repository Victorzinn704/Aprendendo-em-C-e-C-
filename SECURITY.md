# Politica de Seguranca

## Escopo

Este repositorio contem exercicios em C/C++, scripts e demo web. Relate problemas de seguranca ligados a memoria, entrada mal validada, scripts, dependencias web ou workflow de publicacao.

## Como reportar

Nao abra issue publica com payload exploravel que possa ser usado contra terceiros. Use um contato privado indicado no perfil do GitHub ou um aviso privado de seguranca quando o recurso estiver disponivel.

Inclua:

- arquivo e exercicio afetado;
- compilador/sistema operacional;
- entrada usada para reproduzir;
- impacto esperado;
- evidencia redigida.

## Dados e exemplos

Entradas de teste devem ser ficticias. Nao versionar binarios locais, dumps, logs de execucao com dados pessoais ou artefatos de build.
