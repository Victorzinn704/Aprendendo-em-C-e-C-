# PRD - Aprendendo em C e C++

## 1. Objetivo

Criar um repositorio de portfolio que mostre conhecimento pratico em C, estruturas de dados, simulacao de redes, expansao em C++ e documentacao tecnica com evidencias.

## 2. Usuarios

| Persona | Necessidade |
| --- | --- |
| Professor | Ver que todos os exercicios do PDF foram compreendidos e implementados. |
| Recrutador tecnico | Avaliar organizacao, C, ponteiros, estruturas e documentacao. |
| Autor do portfolio | Reusar o repositorio como base para estudos futuros em redes e C++. |

## 3. Requisitos Funcionais

| ID | Requisito | Aceite |
| --- | --- | --- |
| RF-01 | Implementar Exercicio 1 em C | Demo imprime fila, pilha, lista e respostas. |
| RF-02 | Implementar Exercicio 2 em C | Demo imprime chamados, logs e equipamentos. |
| RF-03 | Registrar ausencia do Exercicio 3 | Documento explicita que nao existe no PDF. |
| RF-04 | Implementar Exercicio 4 em C | Processo de maior prioridade executa primeiro. |
| RF-05 | Implementar Exercicio 5 em C | Demo cobre fila, pilha, lista e perguntas teoricas. |
| RF-06 | Adicionar trilha C++/redes | Exemplo de topologia com menor caminho. |
| RF-07 | Criar interface web para GitHub Pages | TypeScript apresenta as questoes do PDF sem afirmar backend online. |
| RF-08 | Documentar funcionamento com evidencias | README, guias, screenshots e relatorio de validacao explicam como rodar e comprovar. |
| RF-09 | Registrar casos de uso | `docs/use-cases.md` conecta as estruturas com situacoes reais. |
| RF-10 | Manter rastreabilidade de validacao | `docs/testing/use-case-test-matrix.md` liga requisito, codigo, teste, evidencia e limite conhecido. |

## 4. Requisitos Nao Funcionais

| Area | Meta |
| --- | --- |
| Portabilidade | Programas C sem dependencia externa. |
| Clareza | Cada exercicio deve compilar isoladamente. |
| Manutencao | Arquivos pequenos, nomes claros e dados de demo sinteticos. |
| Apresentacao | README deve explicar como compilar e rodar. |
| Evidencia | Testes e prints devem ser registrados sem dados sensiveis. |

## 5. Fora Do Escopo Inicial

- sockets reais;
- banco de dados;
- simulacao TCP/IP completa;
- publicacao automatica de backend nativo no GitHub Pages.

## 6. Definition Of Done

- [x] Cada exercicio C compila.
- [x] Cada exercicio C executa uma demo automatica.
- [x] C++ fica documentado e compilavel quando houver compilador.
- [x] README explica escopo e comandos.
- [x] PDF esta mapeado sem inventar exercicio ausente.
- [x] Repositorio Git local inicializado.
- [x] Interface web esta documentada como camada frontend.
- [x] GitHub Pages mostra as questoes do PDF em uma aplicacao unica.
- [x] Skill documental define como manter README, testes e evidencias alinhados ao codigo.
- [x] Casos de uso explicam onde as estruturas aparecem no dia a dia.
- [x] Matriz de rastreabilidade conecta PDF, codigo, testes, evidencias e limites.
