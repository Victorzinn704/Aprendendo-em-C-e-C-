# Roadmap C++ E Redes

## Objetivo

Usar o repositorio para evoluir de exercicios academicos em C para projetos mais fortes de C++ e redes.

## Proximas Frentes

| Frente | Linguagem | Ideia | Valor tecnico |
| --- | --- | --- | --- |
| Topologia com menor caminho | C++ | Grafo com Dijkstra | STL, grafos, redes |
| Simulador ARP/DNS | C++ | Resolver nomes e MACs em tabelas | Modelagem de protocolos |
| Analisador de logs | C | Ler logs sinteticos e sumarizar falhas | Parsing, arquivos, structs |
| Simulador de roteamento | C++ | Tabela de rotas e custo | Redes e algoritmos |
| Cliente TCP local | C/C++ | Socket local controlado | Networking real |

## Regra De Evolucao

Cada nova frente deve ter:

- README curto;
- comando de build;
- demo local;
- dados sinteticos;
- explicacao tecnica e nao tecnica;
- limite claro do que nao esta simulando.
